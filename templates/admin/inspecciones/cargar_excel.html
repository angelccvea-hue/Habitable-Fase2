Flujo recomendado
  1. Descargar plantilla Excel desde la ficha del caso.
  2. Completar secciones de visita (3–11) en Excel — incluye bloque Losas.
  3. Volver aquí y subir el archivo para actualizar el sistema.
  4. Adjuntar croquis y fotos en la ficha solo cuando vaya a elevar o generar PDF.

Las celdas vacías del Excel no borran datos ya guardados en la ficha. Si un desplegable tiene un valor inventado, ese campo se omite y el resto sí se carga.

Si falla: use siempre la plantilla descargada del sistema (no copie a un Excel nuevo), guarde como .xlsx y verifique que el ID Habitable coincida con esta ficha.
